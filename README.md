# 🕒 Digital Clock with Dark Mode

A simple and stylish digital clock built using HTML, CSS, and JavaScript.  
Features include:

- Live time display (HH:MM:SS)
- AM/PM format
- Dark mode toggle
- Theme persistence with `localStorage`
- Responsive and glassmorphism-inspired design


## 📁 Technologies

- HTML5
- CSS3 (with gradients & glassmorphism)
- JavaScript (Date object, DOM, localStorage)

## 🛠 How to Use

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Click the moon icon to switch between light and dark mode.
